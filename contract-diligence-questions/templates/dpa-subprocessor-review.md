# DPA / Sub-processor Review

18 columns for data-protection diligence: controller/processor roles, data categories, sub-processor and breach-notice terms, security measures, audit rights, cross-border transfer mechanism, SCC module, deletion-on-termination, and HIPAA BAA.

18 questions.

| # | Column | Question | Answer type | Options |
|---|--------|----------|-------------|---------|
| 1 | Controller / Business | Who is the data controller (GDPR) or business (CCPA) under this agreement? | Party name |  |
| 2 | Processor / Vendor | Who is the data processor or service provider (the vendor)? | Party name |  |
| 3 | Vendor role | How is the vendor designated for data-protection purposes? | Single select | processor, sub-processor, service provider, controller, unclear |
| 4 | Categories of personal data | What categories of personal data are processed under the agreement? | Free text |  |
| 5 | Categories of data subjects | Whose personal data is processed (categories of data subjects)? | Free text |  |
| 6 | Nature / purpose of processing | What is the stated nature and purpose of the processing? | Free text |  |
| 7 | Sub-processors permitted | Does the agreement permit the vendor to engage sub-processors? | Yes / No |  |
| 8 | Sub-processor notice / objection | What prior notice or objection right does the customer have before a new sub-processor is engaged? | Free text |  |
| 9 | Breach notification window | Within what timeframe must the vendor notify the customer of a personal data breach? | Free text |  |
| 10 | Security measures (TOMs) | Does the agreement specify technical and organizational security measures (e.g., encryption, access controls, an Annex)? | Yes / No |  |
| 11 | Audit rights | Does the customer have audit or inspection rights (or a SOC 2 / ISO 27001 report in lieu)? | Yes / No |  |
| 12 | Cross-border transfer mechanism | What mechanism governs international transfers of personal data? | Single select | EU SCCs (2021), UK Addendum / IDTA, adequacy decision, BCRs, none stated, not applicable |
| 13 | SCC module | Which Standard Contractual Clauses module applies, if stated? | Single select | Module 1 (C2C), Module 2 (C2P), Module 3 (P2P), Module 4 (P2C), not stated, N/A |
| 14 | Deletion / return on termination | Does the vendor agree to delete or return personal data on termination? | Yes / No |  |
| 15 | Data-subject request assistance | Does the vendor agree to assist the customer with data-subject rights requests (access, deletion, portability)? | Yes / No |  |
| 16 | HIPAA BAA included | Does the agreement include or reference a HIPAA Business Associate Agreement (where PHI is involved)? | Yes / No |  |
| 17 | Breach liability / indemnity | How is liability or indemnification for a data breach allocated between the parties? | Free text |  |
| 18 | Governing law | What law governs the data processing agreement? | Free text |  |
